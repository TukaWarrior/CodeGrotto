Algorithm self-test

Six frozen input/output pairs are re-derived on every load. Any edit to the iterations, alphabet, separators, salt or info layout — or a change in browser behaviour — fails here immediately, rather than when an old password stops working. One vector uses a decomposed Unicode accent so it passes only while normalization is intact; another is 64 characters long, which needs a second HKDF block and is the only coverage of that path.
